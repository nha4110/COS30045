About This Project

Data visualization and energy consumption analysis for Australian households.

Project Overview

This demonstration website was developed as part of a web-based data visualization unit at Swinburne University of Technology. It explores core front-end technology foundations including standard HTML5 structure, modular CSS layout design, vanilla JavaScript interactivity, and Git version control workflows.

Objectives & Goals

  • Demonstrate clean semantic multi-page web architecture.
  • Implement accessible UI patterns including accordions and client-side calculators.
  • Establish foundations for upcoming interactive data visualizations with D3.js.
  • Practice responsible usage and critical reflection of Generative AI tools in web software workflows.
