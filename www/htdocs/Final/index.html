About the data, suppression and interpretation

Data governance: First Nations data should be interpreted in line with Indigenous data sovereignty and the context in which the source data was collected. This dashboard does not infer identity or fill gaps.

Suppressed and missing values: Blank, non-numeric and explicit suppression values (such as NaN or “suppressed”) are excluded from calculations, not treated as zero. A missing value is not evidence of no injuries.

Counts and population: Charts show raw hospitalisation counts. Jurisdictions have different population sizes and exposure; these visualisations are not per-capita comparisons and do not establish causation.

Reporting criteria: The 2012 Victoria Emergency Department reporting-criteria change and 2017 NSW reporting-criteria change are marked on the national trend. These administrative breaks may affect comparability.

Suppression: Source rows flagged as suppressed are never converted to zero. State bars and First Nations points identify known subtotals when some categories are suppressed; their tooltips report the excluded category count.

Source: team-prepared BITRE data files. See the project README for expected filenames, supported column names and limitations.
