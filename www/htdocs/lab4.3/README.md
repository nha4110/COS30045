# Appliance Energy Consumption Website

## Project Aim
This website demonstrates core web development concepts by exploring household appliance energy consumption in the Australian market. Developed for **Exercise 0.2** (COS30045 Data Visualisation), this project showcases clean HTML structure, custom responsive CSS styling, dynamic client-side JavaScript interactivity, and version control best practices using GitHub.
