About This Project

Unit context, data processing methodology, and governance ethics.

Project Overview & Educational Context

This web application was developed for Exercise 3: Communicating Data Insights in COS30045 Data Visualisation at Swinburne University of Technology. It combines front-end technology foundations (HTML5, CSS, vanilla JS) with backend data wrangling executed in KNIME Analytics Platform.

About the Data

  • Data Source: Official Australian Government Equipment Energy Efficiency (E3) Program dataset (energyrating.gov.au).
  • Data Processing: Cleaned string variations, filtered non-Australian/unavailable models, converted centimeters to inches, and aggregated energy metrics using KNIME Analytics Platform.
  • Privacy & Ethics: All data consists strictly of public government product appliance specifications. No personally identifiable information (PII) is involved.
  • Accuracy & Limitations: Energy values reflect standardized laboratory test conditions and labelled star ratings; actual home consumption varies based on screen brightness settings, user viewing hours, and HDR content usage.
